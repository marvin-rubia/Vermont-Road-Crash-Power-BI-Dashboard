# Vermont-Road-Crash-Power-BI-Dashboard
This repository contains the source data I used to build my Vermont Road Crash Dashboard, along with blog links that describe my process, from cleaning the dataset to designing the dashboard.

## A 6-Step Data Prep Process Before Any Visualization
[This blog](https://medium.com/data-science-collective/a-6-step-data-prep-process-before-any-visualization-91f139b04411?sharedUserId=marvinrubia) covers the data-cleaning steps I had to do to prepare the road crash data for visualization.

## How to Design a Dashboard to Communicate Business Insights Clearly
In [this blog](https://medium.com/data-science-collective/how-to-design-a-dashboard-to-communicate-business-insights-clearly-192490fc4868?sharedUserId=marvinrubia), I tackle the 3 guiding pillars I used to develop this dashboard and others throughout my analytics career: __clarity of insights__, __user-friendliness__, and __visual hierarchy__.
